# Homebrew Taps

This repository houses custom Homebrew formula (a.k.a, a [tap](https://docs.brew.sh/How-to-Create-and-Maintain-a-Tap)). 

## Formula

| Formula | Description | Install |
| -- | -- | -- |
| BrewPy | Simple alternative to pyenv that just works | brew install landoncrabtree/tap/brewpy |
| binutils-x86-64 | Patched version of [pwntools-binutils](https://github.com/Gallopsled/pwntools-binutils/tree/master/macos) with fixes to compile on newer macOS versions | brew install landoncrabtree/tap/binutils-x86-64 |
